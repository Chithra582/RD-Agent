# Experiment Code Synthesis

## Overview
This skill operationalizes the translation of abstract research hypotheses into production-quality, vectorized Python code, building complete data pipelines, factor calculators, and neural network architectures.

## Key Capabilities
- **Vectorized Data Processing**: Implements performant NumPy, Pandas, Polars, and PyTorch data operations.
- **Model Pipeline Authoring**: Writes modular training loops, loss functions, and optimization schedules.
- **Code Hardening**: Incorporates robust safeguards against numerical underflow/overflow, division-by-zero, and data leakage.

## Operational Workflow
1. **Hypothesis Intake**: Receive research proposal with specified transformations and mathematical formulas.
2. **Architecture Formulation**: Author modular classes conforming to standard interfaces (e.g., Qlib factor processors, PyTorch Lightning modules).
3. **Static Validation**: Check syntax, import availability, and dimension alignment.
4. **Patch Application**: Write or update files in the target experiment workspace.
